AgaShop · Flujos de usuario

Cada flujo parte de lo que la persona quiere lograr, no de lo que hace el sistema. El diagrama muestra solo las pantallas que ve y las decisiones que toma. Debajo de cada uno, cómo debe actuar el diseño para acompañarla.

Quién usa el sistema (personas supuestas, a validar con entrevistas)

Cajera o cajeroEstá de pie, con clientas esperando. Quiere cobrar rápido y no equivocarse con el dinero. Usa el sistema todo el día y no quiere pensar.
Supervisor/aResuelve lo que la caja no puede: autoriza, corrige, repone. Quiere saber de un vistazo si algo va mal, sin buscar.
Administrador/a o dueño/aConfigura y decide. Entra pocas veces. Necesita confiar en que el negocio está bajo control.
